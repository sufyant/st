# apps/web Tema Toggle Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `apps/web` dashboard'una `next-themes` ile Light/Dark/System tema secimi eklemek; secim `NavUser` dropdown'inda bir "Theme" alt-menusu olarak sunulur.

**Architecture:** shadcn'in resmi `next-themes` deseni. `class` attribute'una gore CSS degiskenleri zaten `packages/ui/src/styles/globals.css`'te `.dark` selector'iyla tanimli — degismiyor. Yeni olan: `<html>`'e `dark` class'ini ekleyip/cikaran `next-themes` runtime'i, ve bunu kontrol eden bir dropdown radio-group.

**Tech Stack:** Next.js 16.3.4 (App Router), React 19, `next-themes`, mevcut `@st/ui` (Radix tabanli) dropdown-menu primitifleri.

## Global Constraints

- `next-themes` sadece `apps/web`'e eklenir, `packages/ui`'a eklenmez (bkz. spec: [2026-09-06-web-tema-toggle-design.md](../specs/2026-09-06-web-tema-toggle-design.md), "Kararlar" bolumu).
- `packages/ui`'da yeni component olusturulmaz; mevcut `DropdownMenuSub`, `DropdownMenuSubTrigger`, `DropdownMenuSubContent`, `DropdownMenuRadioGroup`, `DropdownMenuRadioItem`, `DropdownMenuPortal` kullanilir (`packages/ui/src/components/ui/dropdown-menu.tsx`).
- Repo'da test framework yok (`vitest`/`jest` yok). Dogrulama gecitleri: `pnpm turbo check-types` (tip guvenligi) + Claude Browser ile dev server uzerinden manuel/otomatik gorsel dogrulama. Yeni bir test framework kurmak bu planin kapsami disinda.
- Paket yoneticisi `pnpm@10.30.3`; bagimlilik eklerken `pnpm --filter @st/web add <paket>` kullanilir (kok `package.json` degil, `apps/web/package.json` guncellenir).
- Bicimlendirme Biome ile yapilir (`pnpm format`); import siralamasi elle degil, Biome'a birakilir.

```tsx
"use client";

import { ThemeProvider as NextThemesProvider } from "next-themes";
import type * as React from "react";

export function ThemeProvider({ children }: { children: React.ReactNode }) {
  return (
    <NextThemesProvider
      attribute="class"
      defaultTheme="system"
      enableSystem
      disableTransitionOnChange
    >
      {children}
    </NextThemesProvider>
  );
}
```
